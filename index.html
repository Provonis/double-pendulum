Linear theory check

Small-angle normal modes for the current masses, lengths and g. Excite one, run it, and compare the measured θ₁ period. The theory is exact only as the amplitude → 0; raise it to see the period shift. The motion is small on screen, so watch the traces or Angles vs t.

Sensitivity

A second pendulum starts with θ₂ shifted by δ. Watch the Divergence plot to see how fast they separate. Changing δ restarts the run; turning the shadow on mid-run starts it from the current state.

About the model
  • Point masses on massless rigid rods, frictionless pivots. Positions: x₁ = l₁ sin θ₁, y₁ = −l₁ cos θ₁, x₂ = x₁ + l₂ sin θ₂, y₂ = y₁ − l₂ cos θ₂.
  • θ̈₁ and θ̈₂ are the same closed-form expressions as eom_double_pendulum, and E = T + U is the same as compute_energy.
  • Energy error is normalized like the notebook: (E − E₀) / [(m₁+m₂) g l₁ + m₂ g l₂]. With g = 0 that scale is zero, so |E₀| is used instead.
  • Integration is fixed-step RK4 (the notebook uses adaptive DOP853 with rtol 1e-7, atol 1e-14). Halving h should cut the RK4 energy error by about 16×. For chaotic initial conditions the path itself will still differ after roughly 10 s (that is the sensitivity the Divergence plot shows), so compare energy error and overall behaviour, not the exact path.
  • Air drag is an optional extension: a force −c v on each bob, added as generalized forces. The energy lost to drag is integrated alongside, so the energy error still measures only numerical error.
